Структура и проверка XML

Well-formed XML соблюдает синтаксис. Валидный XML дополнительно соответствует заранее заданной модели документа.

DTD

DTD (Document Type Definition) может описывать допустимые элементы, их порядок и атрибуты.

<!DOCTYPE note [
  <!ELEMENT note (to,from,body)>
  <!ELEMENT to (#PCDATA)>
  <!ELEMENT from (#PCDATA)>
  <!ELEMENT body (#PCDATA)>
]>

XML Schema (XSD)

XSD — XML-ориентированный язык схем. Он поддерживает типы данных, ограничения значений и пространства имён.

<xs:element name="year">
  <xs:simpleType>
    <xs:restriction base="xs:integer">
      <xs:minInclusive value="1900"/>
      <xs:maxInclusive value="2100"/>
    </xs:restriction>
  </xs:simpleType>
</xs:element>

Два уровня проверки

  1. Синтаксическая корректность: парсер может построить дерево.
  2. Валидность: дерево соответствует DTD/XSD или другой схеме.

Полезно помнить

XML описывает структуру данных, а не их внешний вид. Для оформления и преобразований применяются отдельные технологии.
