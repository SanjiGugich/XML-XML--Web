XML и JSON

XML и JSON решают похожую задачу передачи структурированных данных, но используют разные модели записи и имеют разные сильные стороны.

Сравнение XML и JSON
КритерийXMLJSON
Основная модельДерево элементов и атрибутовОбъекты, массивы и значения
КомментарииПоддерживаютсяСтандарт JSON комментарии не определяет
NamespacesЕсть стандартный механизмНет встроенного аналога
СхемыDTD, XSD и другиеJSON Schema
Смешанное содержимоеУдобно для документной разметкиОбычно менее естественно
Типичный API WebВстречается, особенно в legacy/SOAPОчень распространён в REST API

Одинаковые данные

XML

<user>
  <name>Alex</name>
  <skills>
    <skill>HTML</skill>
    <skill>CSS</skill>
  </skills>
</user>

JSON

{
  "name": "Alex",
  "skills": ["HTML", "CSS"]
}
Выбор формата зависит от задачи: JSON часто удобнее для API и JavaScript, а XML особенно силён там, где важны namespaces, схемы, документная структура и развитая экосистема XML-инструментов.

Полезно помнить

XML описывает структуру данных, а не их внешний вид. Для оформления и преобразований применяются отдельные технологии.
