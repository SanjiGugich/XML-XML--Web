Синтаксис XML

XML использует элементы, атрибуты и строгую вложенность. Документ должен быть синтаксически корректным (well-formed).

Основные правила

  • В документе должен быть ровно один корневой элемент.
  • Каждый открывающий тег должен быть корректно закрыт.
  • Элементы нельзя перекрёстно вкладывать.
  • Имена тегов чувствительны к регистру.
  • Значения атрибутов заключаются в кавычки.

Корректный пример

<?xml version="1.0" encoding="UTF-8"?>
<student id="101">
  <name>Александр</name>
  <group>ИСиТ</group>
</student>

Некорректный пример

<student>
  <name>Александр
  <group>ИСиТ</name>
</student>
Почему ошибка: элемент name не закрыт перед началом group, а закрывающие теги нарушают вложенность.

Полезно помнить

XML описывает структуру данных, а не их внешний вид. Для оформления и преобразований применяются отдельные технологии.
