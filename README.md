XML в Web

Учебный многостраничный сайт по теме «XML и XML-словари в Web», выполненный в рамках проекта по использованию CSS-фреймворков.

Сайт знакомит с основами XML, его синтаксисом, структурой документов, пространствами имён, XML-словарями, XPath, XSLT, а также содержит сравнение XML и JSON и практические примеры.

Структура сайта

Проект состоит из 9 связанных страниц:

Главная — введение в XML и области его применения.

Синтаксис XML — элементы, атрибуты, вложенность и правила корректной записи.

Структура и проверка XML — DTD, XSD, well-formed и valid XML.

Пространства имён — использование xmlns и префиксов.

XML-словари — SVG, XHTML, MathML, RSS, RDF и другие XML-языки.

XPath — выбор и адресация узлов XML-документа.

XSLT — преобразование XML в другие форматы, включая HTML.

XML и JSON — сравнение двух форматов представления данных.

Примеры и практика — код, видео и небольшой интерактивный тест.

Запуск проекта локально

Проект является статическим сайтом и не требует установки сервера или дополнительных зависимостей.


Вариант 1

Откройте файл index.html в браузере.


Вариант 2

Можно запустить локальный сервер, например через расширение Live Server в Visual Studio Code.

Публикация на GitHub Pages

Создайте новый репозиторий на GitHub.

Загрузите в него все файлы проекта.

Перейдите в Settings → Pages.

В разделе Build and deployment выберите Deploy from a branch.

Укажите:

Branch: main

Folder: / (root)

Сохраните настройки.


Проверка проекта

Перед сдачей рекомендуется проверить:

корректность всех ссылок между страницами;

адаптивность на разных разрешениях;

работу мобильного меню;

отображение таблиц и изображений;

работу JavaScript;

валидность HTML через W3C Validator;

отсутствие лишних и закомментированных фрагментов кода;

наличие актуальных ссылок на GitHub Pages и репозиторий.
