XML-словари

XML-словарь — соглашение о наборе элементов, атрибутов, пространствах имён и правилах их совместного использования для конкретной предметной области.

SVG

Scalable Vector Graphics описывает двумерную векторную графику, формы, пути, текст и фильтры.

MathML

Markup-язык для представления математических выражений и их семантики.

RSS

Семейство XML-форматов для лент публикаций и обновлений сайтов.

Atom

Стандартизированный формат Web-лент и связанный протокол публикации.

RDF/XML

Один из синтаксисов представления RDF-графов в XML.

XHTML

Формулировка HTML с требованиями XML-синтаксиса.

Мини-пример SVG как XML

<svg xmlns="http://www.w3.org/2000/svg" width="200" height="120">
  <rect x="10" y="10" width="180" height="100" rx="12" fill="#5e2750"/>
  <text x="100" y="70" text-anchor="middle" fill="white">XML</text>
</svg>

Браузер интерпретирует элементы rect и text согласно правилам словаря SVG.

Полезно помнить

XML описывает структуру данных, а не их внешний вид. Для оформления и преобразований применяются отдельные технологии.
